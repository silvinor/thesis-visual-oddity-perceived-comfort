Appendix D
SPSS Syntax and Output for the Reported Analyses

All analyses were run in IBM SPSS Statistics (Version 31.0.1.0), with the PROCESS macro (Version 4.2; Hayes, 2017) for the mediation models. Each section gives the syntax that was run and the output it produced. PROCESS output is reproduced verbatim; the regression tables are transcribed from the SPSS output file, with values shown at the precision SPSS displayed them.

Variables: c_discom = discomfort (1–4, higher = more discomfort); c_expect = perceived unexpectedness (1–5, higher = more unexpected); c_oddity = oddity (0 = absent, 1 = present); c_noise = activity level (0 = low, 1 = high); c_oddnse = c_oddity × c_noise.

  • D1. Multiple regression of discomfort on oddity, activity level and their interaction (H1 and H2)
  • D2. Mediation of oddity on discomfort by perceived unexpectedness, rating level (H3)
  • D3. Mediation re-estimated on participant × condition means (sensitivity analysis)

D1. Multiple Regression (H1 and H2)

N = 2,688 ratings. Ordinary least squares standard errors.

Syntax

REGRESSION
  /DESCRIPTIVES MEAN STDDEV CORR SIG N
  /MISSING LISTWISE
  /STATISTICS COEFF OUTS CI(95) R ANOVA COLLIN TOL CHANGE ZPP
  /CRITERIA=PIN(.05) POUT(.10) TOLERANCE(.0001)
  /NOORIGIN
  /DEPENDENT c_discom
  /METHOD=ENTER c_oddity c_noise c_oddnse

  /CASEWISE PLOT(ZRESID) OUTLIERS(3)

D2. Mediation Analysis (H3)

N = 2,688 ratings. PROCESS Model 4 with activity level as a covariate, HC4 standard errors, 10,000 bootstrap samples and a fixed random seed (20260727), so the bootstrap interval for the indirect effect can be reproduced exactly.

Syntax

PROCESS
    y=c_discom
    /x=c_oddity
    /m=c_expect
    /cov=c_noise
    /model=4
    /boot=10000
    /conf=95
    /hc=4
    /effsize=1
    /stand=1
    /total=1
    /seed=20260727.
