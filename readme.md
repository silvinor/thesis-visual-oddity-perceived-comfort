- **Supplementary R analysis scripts and outputs**
    
    *Note.* These were not used in the thesis. They where generated by AI to verify the SPSS data, and as a learning opportunity to extend the authors R knowledge.

    - `r/h3_age_split.R` - Repeats H3 by age group.
    - `r/h3_full_set.R` - Repeats H3 with the full data set.
    - `r/h3_gender_split_model_59.R` - Tests gender as an H3 moderator.
    - `r/h3_gender_split.R` - Repeats H3 by gender.
    - `r/h3_propensity_split.R` - Repeats H3 by travel propensity.
    - `r/h3_timezone_split.R` - Repeats H3 by time zone.
    - `r/h4_direct_effect_probe.R` - Examines the negative direct effect.
    - `r/response_validation.R` - Tests response quality and speed sensitivity.
    - `r/timer_stats.R` - Summarizes demographics and completion times.
    - `r/outputs/*` - Contains reports from the R scripts.
